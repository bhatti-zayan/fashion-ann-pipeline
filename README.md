# Fashion-MNIST ANN Pipeline

This project implements a reproducible Machine Learning pipeline for the Fashion-MNIST dataset using tensorflow, git and DVC.

The model is a fully connected artificial neural network (ANN) that classifies Fashion-MNIST images into one of ten clothing categories.

The project demonstrates source-code version control with git, data and model versioning with DVC, google drive remote storage, and reproducible machine learning pipelines.
